# 대학로 자율주행 역할 3 실험 공유

이화사거리에서 혜화동로터리까지 주행하는 AV의 역할 3 실험을 정리했다. 세 역할의 비교에 사용할 도로·교통 규칙과 모델 입출력 명세를 팀이 검토할 수 있도록 평가 코드, 모델, 도로 후보와 재현 자료를 함께 제공한다. **공통 환경은 팀 검토 중이다.**

## 결과

각 행은 같은 난수와 출발 시각으로 120회씩 실행한 짝지은 비교다. 동일 도로에서 모델을 비교하는 실험과 동일 모델에서 도로만 바꾼 실험을 구분했다.

| 시드 시작값 | 달라진 조건 | 충돌 건수 | 전체 도착 | 무위반 도착 | 장기 정차 | 경로 이탈 |
|---|---|---:|---:|---:|---:|---:|
| 820000 | 평가 도로, 기준 모델 → 감속 학습 모델 | 11 → 5 | 95 → 107 | 82 → 95 | 9 → 4 | 4 → 4 |
| 840000 | 평가 도로, 기준 모델 → 감속 학습 모델 | 10 → 7 | 95 → 100 | 85 → 84 | 6 → 5 | 9 → 8 |
| 830000 | 로터리 경계 후보, 기준 모델 → 감속 학습 모델 | 10 → 6 | 102 → 107 | 83 → 83 | 2 → 3 | 5 → 3 |
| 860000 | 감속 학습 모델, 로터리 경계 후보 → 조기 차선 변경 후보 | 13 → 8 | 98 → 96 | 77 → 81 | 3 → 4 | 6 → 12 |

평가 도로의 첫 두 독립 묶음에서 감속 학습 모델은 12/240회 충돌했다. 새 870000번대에서는 이 모델이 13/120회, 추가 감속 학습 모델이 18/120회 충돌해 추가 모델은 채택하지 않았다. 공유 모델의 같은 도로 세 묶음 합계는 25/360회(6.94%)로 수업 기준인 **5% 미만**을 아직 충족하지 못했다. 위 비교에서는 AV 및 배경 차량 텔레포트와 관측 조회 오류가 모두 0건이었다. [전체 에피소드 기록](evidence/evaluation_results.json) · [추가 감속 대조](evidence/latest_braking_ablation.json)

감속 학습은 별도 학습 시드에서 충돌이 난 주행을 재현한 뒤, 더 일찍 감속해 무위반 도착한 18개의 오프라인 전문가 시범을 이용했다. 시드 기준으로 14개를 학습, 4개를 검증에 썼다. 가감속 관련 가중치 세 텐서만 갱신했다. 평가에서는 단일 신경망이 가감속·차선 변경을 결정한다.

차선 변경을 일찍 허용한 도로의 AV 이탈 12건 중 8건은 로터리의 `arcN2_1`, 4건은 `nb_O_I_4`에서 발생했다. 같은 차로에서 긴급차가 뒤에서 접근한 860000번대 전체 11개 주행을 재현했다. 접근 중 실제 차선 변경을 한 관측 하나에서 긴급차 입력만 중립값으로 바꿔 다시 추론하자 차선 명령이 달라졌다. [상호작용 재현 기록](evidence/traffic_results.json)

## 공통 환경을 고정할 때

1. 먼저 검증한 도로를 한 개 선택하고 네트워크, 신호, 교통 수요, 출동 규칙과 SUMO 버전을 함께 고정한다. 현재 실행은 0.5초 간격, 정차 텔레포트 `-1`, AV 240초 연속 정차 시 실패를 사용한다. 긴급차 위치에 맞춰 신호를 바꾸는 실행 중 보조는 사용하지 않는다.
2. 일반 차량만으로 한 시간 돌리는 도로 검사와 AV 주행 검사를 모두 실시한다. 출동 예정 시각과 실제 투입 시각, 장기 대기, 경로 이탈, 충돌, 텔레포트를 기록한다.
3. 세 역할의 시드, 출발 시각, AV 경로와 성공·실패 정의를 동일하게 고정한다. 도로·교통을 변경하면 버전을 올려 세 모델을 같은 새 버전에서 재평가한다.

| 포함 환경 | 내용 |
|---|---|
| `evaluated` | 820000·840000번대 평가와 데모에 사용. 로컬 실험에서 일부 합류 및 횡단 신호, 긴급차 적신호 통과 예외, 구급차 출발 차로를 수정했다. 두 긴급차의 예정 출동 시각은 1500초다. |
| `rotary_radius` | 위 환경에서 북쪽 로터리 J_N 경계 반경을 2m로 조정했다. |
| `rotary_early_lane_change` | 반경 후보에서 `arcE_3` 일반 차량의 왼쪽 차선 변경을 허용했다. 경로 이탈 증가 때문에 공통 채택은 보류한다. |

820098의 AV 없는 한 시간 재현에서, 직진 예정인 일반 차량이 우회전 전용 차로에서 멈춰 300초 이상 대기한 차량이 705대였다. 로터리 경계 후보에서 같은 시드의 300초 이상 대기는 0대였다. 별도 배경 교통 8회에서 경계 후보는 2대, 조기 변경 후보는 0대가 300초 이상 대기했다. 두 후보 모두 긴급차 16대가 무충돌 도착했다. 공유 네트워크의 생성 주석에서 로컬 경로를 제거했으며, 원래 평가 입력과 공유본의 해시를 각각 기록했다. [도로 환경과 모델 해시](evidence/evaluation_contract.json) · [배경 교통 평가](evidence/traffic_results.json)

## 모델을 서로 실행하려면

현재 조원 BC 체크포인트는 49개 관측과 연속형 차선 변경 값을 쓴다. 역할 3은 65개 관측과 좌·유지·우 분류를 쓴다. 두 체크포인트를 서로의 로더에 넣고 반대 길이의 벡터도 입력해 봤으며 모두 거부됐다. 기존 49개에는 추천 차로와 필요 감속 정보가 들어 있어 프로젝트 규정에 따라 새 공통 관측에서 제외해야 한다. [교차 입력 및 로더 검증 결과](evidence/compatibility.json)

공통 규격에는 관측의 이름, 순서, 단위, 정규화, 결측값, 이력 간격과 물리 행동의 단위 및 방향을 명시한다. `evaluation_contract.json`의 65개 관측은 검토용 초안이다. 조원마다 신경망 구조와 출력 헤드가 달라도 공통 환경이 받는 가감속과 좌·유지·우 명령으로 동일하게 해석할 수 있다. 기존 관측값에 0을 채우거나 열을 임의로 잘라서 복원할 수 없는 입력이 있으므로, 세 역할을 비교할 때는 합의한 공통 관측으로 BC 데이터를 다시 추출하고 각 모델을 학습한다. 그 뒤 동일 평가기와 동일 시드에서 실행한다.

```shell
python check_model_compatibility.py models/role3_collision_braking.pt path/to/team_model.pt
```

## 데모 실행

Python 3.13 및 SUMO 1.27.1에서 검증했다. SUMO를 설치한 뒤 `SUMO_HOME`과 실행 파일 경로를 설정하고 의존성을 설치한다. `evaluate_policy.py`나 모델 검사에서 PyTorch도 필요하다. 데모는 학습된 가중치에서 내보낸 NumPy actor를 쓰므로 PyTorch 설치 없이 실행할 수 있다.

```shell
python -m pip install -r requirements.txt
python replay_policy.py
python replay_policy.py --gui
```

Windows에서 가상환경을 활성화한 뒤 [watch_role3_demo.bat](watch_role3_demo.bat)를 실행해도 된다. 데모는 독립 평가에서 고른 820045번 사례다. AV가 시뮬레이션 1342.5초에 투입되어 304초 만에 무충돌·무위반 도착했고, 차선 변경 3회와 가까운 긴급차 접근이 기록됐다. 창은 AV를 추적하고, 주행이 끝나면 콘솔에서 Enter로 닫을 수 있다. 화면 없는 SUMO에서 LibSUMO와 TraCI 양쪽으로 완주 및 전체 이벤트 집계를 재현했다. [데모 설정과 검증값](evidence/demo_case.json)

820000번대 120회 전체를 재현할 때는 `evaluation_results.json`의 `start_times_s`를 그대로 전달한다.

```shell
python evaluate_policy.py --run environments/evaluated --model models/role3_collision_braking.pt --episodes 120 --seed 820000 --windows 462 769 1070 1342 1468 1522 --dump 2
```

도로와 기본 환경의 출처는 [팀 도로 저장소](https://github.com/junyeounyang/daehakro_final)와 [팀 BC 실험 저장소](https://github.com/junyeounyang/Artificial-Intelligence-and-Control-for-Autonomous-Driving)다. 정확한 기반 커밋은 평가 명세에 기록했다.
